# joon — 가상 생산기술 사무실

**총괄 실장 1명 + AI 직원 8명**이 일하는 가상 사무실입니다.
이 저장소에서 Claude Code 세션을 열면 **총괄 실장**이 응대합니다. 총괄에게만 지시하면 업무를 쪼개 담당 직원에게 배정하고, 결과를 모아 검수한 뒤 두괄식으로 보고합니다.

```
나(팀장) ──지시──▶ 총괄 실장 ──배정──▶ 직원들 (동시/순서대로)
   ▲                   │ ◀──결과──┘
   └──보고──────── 취합 → 감사과장 검수(외부 제출 시)
```

## 조직도

| 직원 | 직함 | 담당 |
|---|---|---|
| `chief-manager` | **총괄 실장** | 지시 접수, 업무 분해·배정, 취합·조정, 보고, 업무일지 |
| `process-engineer` | 공정기술 과장 | 병목, CT 단축, 라인 밸런싱, OEE |
| `equipment-analyst` | 설비보전 과장 | CMMS 고장 이력, MTBF/MTTR, RCA, PM |
| `quality-engineer` | 품질 과장 | 불량 원인, Cpk/SPC, 8D, FMEA, 4M 변경 |
| `cost-analyst` | 원가기획 대리 | 원가 절감, 투자 ROI, 회수기간 |
| `npi-manager` | NPI PM | 신제품 일정, APQP/PPAP, ECN |
| `automation-dev` | 자동화 담당 | VBA 매크로, Python 스크립트 |
| `report-writer` | 기획 대리 | 보고서, PPT 구성안, Notion 문서 |
| `audit-manager` | 감사대응 과장 (겸 검수) | 현대차 공정·시스템감사, 지적사항 CAR, 외부 제출 문서 검수 |

## 사용법

담당자를 고를 필요 없이 그냥 말하면 됩니다.
```
2라인 용접 불량이 지난달부터 늘었어. 원인 찾고 대책 비용 비교해서 다음주 현대차 보고자료까지 만들어줘
12/5 현대차 공정감사 있어. 2라인 D-7 모의감사 준비해줘
이번 주 업무 진행 상황 알려줘
```
- 총괄이 **배정표**(세부업무·담당·입력·산출물·선행)를 먼저 보여줍니다.
- 담당 2명 이하 사내 업무는 바로 진행하고, 3명 이상이거나 외부에 제출하는 업무는 승인을 받은 뒤 진행합니다.
- 특정 직원을 지명해도 됩니다. ("품질과장한테 맡겨줘")

**업무지시서로 맡기기**: `office/templates/업무지시서.md` 를 `office/inbox/` 에 복사해 작성하고 "inbox 업무 처리해줘"라고 하면 됩니다.

## 폴더
| 폴더 | 용도 |
|---|---|
| `office/inbox/` | 업무지시서 |
| `office/data/` | 원본 데이터 (직원은 수정하지 않음) |
| `office/outputs/` | 산출물 (`날짜_업무명/`), `업무일지.md` |
| `office/references/` | 원청 기준서 (기밀) |
| `office/templates/` | 업무지시서, 감사준비 체크리스트, 지적사항 트래커 |

운영 규칙은 [`CLAUDE.md`](CLAUDE.md), 총괄 절차는 [`.claude/agents/chief-manager.md`](.claude/agents/chief-manager.md)에 있습니다.
