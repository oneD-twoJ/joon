# 원청 감사 준비 체크리스트

> 일반 기준(IATF 16949 / VDA 6.3) 기반 초안입니다. 현대차 배포 기준서를 `office/references/`에 넣으면 그 기준으로 갱신합니다.

| 항목 | 내용 |
|---|---|
| 감사 유형 | 공정감사 / 시스템감사 / 기타 |
| 감사 일자 | YYYY-MM-DD |
| 대상 | 라인: / 제품(품번): |
| 감사 주관 | 현대자동차 ○○팀 |
| 직전 감사 지적 | ○건 (완료 ○ / 진행 ○) |

## D-14 범위·이력
- [ ] 감사 범위(라인·제품·공정) 확정
- [ ] 직전 지적사항 시정조치 완료 + 효과확인 증빙
- [ ] 최근 3개월 고객 클레임·불량 현황 정리
- [ ] 4M 변경 이력(신고·승인·초물검증) 정리

## D-7 모의감사 — 문서 정합성
- [ ] PFMEA 최신본(개정일·개정이력) 확인
- [ ] PFMEA ↔ 관리계획서 특성·관리방법 일치
- [ ] 관리계획서 ↔ 작업표준서 ↔ 검사기준서 규격·주기·방법 일치
- [ ] 반응계획(이상 발생 시 조치)이 현장 게시물과 일치
- [ ] 특별특성(CC/SC) 표기 일관성

## D-7 모의감사 — 현장
- [ ] 초·중·종물 검사 기록 누락 없음
- [ ] 측정기 검교정 유효기간 / 라벨 부착
- [ ] 부적합품 식별·격리(적색 박스, 표기)
- [ ] 작업자 교육·자격 인증 이력, 다기능표
- [ ] 에러프루프(Poka-Yoke) 일상점검 기록, 마스터 샘플 관리
- [ ] 설비 일상점검·PM 기록 (CMMS 이력과 일치)
- [ ] 3정5S, 선입선출(FIFO), 식별표

## D-3 / D-1
- [ ] 미비사항 조치 완료 확인
- [ ] 담당자별 예상 질문·답변 숙지
- [ ] 증빙 폴더(전자/바인더) 최종 확인
